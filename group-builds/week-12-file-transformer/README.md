# Week 12 Group Build: File Transformer

## Branch Name

Use this exact feature branch name for this assignment:

```text
week-12-file-transformer
```

Open your pull request from `week-12-file-transformer` into your repo's `main` branch. Submit the PR link in Canvas when this assignment is collected.

Use this folder only if your group wants a shared scratch space. Most weeks, the group build is practice first and Canvas reflection second.

## What To Build

- Create or use a small text file.
- Write a program that reads the file.
- Transform the content in some visible way, such as numbering lines, counting words, or converting case.
- Print the result or write it to a new file.

## Done When

- The program opens and reads a file.
- The transformation result is visible.
- The group can explain why files need to be opened and closed safely.

## Optional Remix

Write the transformed output to a second file.

## Roles

- Driver: types the current version
- Navigator: watches logic and asks questions
- Tester: tries examples and edge cases
- Explainer: prepares the short summary

Rotate roles during class when it helps.

## Reflection Prompt

Each student should be ready to submit a short Canvas reflection: what your group built, what you contributed, and one thing your group learned.
