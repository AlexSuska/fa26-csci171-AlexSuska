# Week 14 Group Build: Algorithm Clinic

## Branch Name

Use this exact feature branch name for this assignment:

```text
week-14-algorithm-clinic
```

Open your pull request from `week-14-algorithm-clinic` into your repo's `main` branch. Submit the PR link in Canvas when this assignment is collected.

Use this folder only if your group wants a shared scratch space. Most weeks, the group build is practice first and Canvas reflection second.

## What To Build

- Choose one problem from recent work that can be solved step by step.
- Write the algorithm in plain English first.
- Turn the algorithm into Python code.
- Test with at least three cases and revise the steps if needed.

## Done When

- The plain-English algorithm is clear.
- The code follows the algorithm.
- The group can explain one revision made after testing.

## Optional Remix

Compare two algorithms for the same task and explain which is clearer.

## Roles

- Driver: types the current version
- Navigator: watches logic and asks questions
- Tester: tries examples and edge cases
- Explainer: prepares the short summary

Rotate roles during class when it helps.

## Reflection Prompt

Each student should be ready to submit a short Canvas reflection: what your group built, what you contributed, and one thing your group learned.
