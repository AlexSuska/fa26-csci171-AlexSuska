# Week 07: Function Suite

## Focus

return values, Boolean helpers, and simple tests.

## Branch Name

Use this exact feature branch name for this assignment:

```text
week-07-function-suite
```

Open your pull request from `week-07-function-suite` into your repo's `main` branch. Submit the PR link in Canvas when this assignment is collected.

## Required Friday Project

Write a set of small functions and test their return values.

Submit your completed code in Canvas by the Friday due date. Run your program before submitting.

## Extra Credit Take-Home Stretch

Add more edge cases and a menu that uses the functions.

The stretch is optional and should build on your required project after the required version works.
